# RUMO-Atlas
Atlas é o Gemini customizado do RUMO. Instruções e prompts que geram trilhas de estudo de programação personalizadas, com módulos e exercícios por nível.

Quando desenvolvido, nós focamos na otimização de tokens na hora de gerar trilhas e avaliar o conteudo pedido pelo usuario.
A IA usa a api grátis do GEMINI porém funciona com parametros privados que apenas nós (criadores do projeto) temos acesso.
